# Документация Docker Cloud Manager

Этот раздел содержит пользовательскую и эксплуатационную документацию Docker Cloud Manager (DCM). Документы описывают фактическое поведение текущей версии репозитория.

> [!IMPORTANT]
> DCM находится в разработке. Текущий вариант развёртывания рассчитан на одну машину с Linux и публикует HTTP-трафик на порту `80`.

| Интегрироваться с HTTP API | [Руководство по API](api-guide.md) |

## Рекомендуемый порядок

### Владелец сервера

1. Ознакомьтесь с [ограничениями текущего развёртывания](deployment-single-vm.md#ограничения-текущего-варианта).
2. Выполните [развёртывание](deployment-single-vm.md).
3. Настройте пользователей и квоты по [руководству администратора](admin-guide.md).

### Пользователь платформы

1. Изучите [основные понятия и состояния ресурсов](user-guide.md#состояния-и-асинхронные-операции).
2. Создайте том и контейнер либо соберите собственный образ.
3. Для многоконтейнерного приложения используйте [руководство по Compose](compose-guide.md).

### Разработчик API-клиента

1. Изучите [модель аутентификации и ошибок](api-guide.md).
2. Используйте [OpenAPI 3.0](../backend/api/gateway/openapi.yml) как справочник маршрутов и схем.
