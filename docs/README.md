# Документация Docker Cloud Manager

Этот раздел содержит пользовательскую, эксплуатационную и техническую документацию Docker Cloud Manager (DCM). Документы описывают фактическое поведение текущей версии репозитория.

> [!IMPORTANT]
> DCM находится в разработке. Текущий вариант развёртывания рассчитан на одну машину с Linux и публикует HTTP-трафик на порту `80`.

## Рекомендуемый порядок

### Владелец сервера

1. Ознакомьтесь с [ограничениями текущего развёртывания](deployment-single-vm.md#ограничения-текущего-варианта) и [моделью безопасности](security-model.md).
2. Выполните [развёртывание](deployment-single-vm.md).
3. Настройте [резервное копирование](operations.md#резервное-копирование).
4. Настройте пользователей и квоты по [руководству администратора](admin-guide.md).

### Пользователь платформы

1. Изучите [основные понятия и состояния ресурсов](user-guide.md#состояния-и-асинхронные-операции).
2. Создайте том и контейнер либо соберите собственный образ.
3. Для многоконтейнерного приложения используйте [руководство по Compose](compose-guide.md).

### Разработчик API-клиента

1. Изучите [модель аутентификации и ошибок](api-guide.md).
2. Используйте [OpenAPI 3.0](../backend/api/gateway/openapi.yml) как справочник маршрутов и схем.
3. Для работы с сессиями прочитайте [контракт сессий](session-security.md).

### Разработчик DCM

1. Настройте окружение по [руководству разработчика](development.md).
2. Устройство клиентской части описано в [`frontend/README.md`](../frontend/README.md).
